# CMX

**CMX** - редактор кода для панели управления **MODX Revolution**, построенный на **CodeMirror 6**. Он заменяет стандартные текстовые поля элементов, файлов, ресурсов и TV полноценным редактором с подсветкой, автодополнением MODX-тегов, проверкой кода, историей версий, черновиками, поиском, Emmet, темами и несколькими раскладками клавиатуры.

Пакет работает локально внутри менеджера: редактор поставляется одним собранным JavaScript-бандлом и не загружает CodeMirror, темы или режимы с внешних CDN.

## Установка и включение

1. В менеджере MODX откройте **Пакеты → Управление пакетами**.
2. Загрузите [`cmx-1.0.0-pl.transport.zip`](https://github.com/vitos88/Cmx/releases) и установите транспортный пакет.
3. Во время установки CMX:
   - выбирает себя в системной настройке `which_element_editor`;
   - создаёт таблицу истории версий `cmx_revision`;
   - регистрирует плагин и его события;
   - добавляет виджет **CMX Scratchpad**.
4. Откройте или обновите страницу редактирования элемента.

Если редактор не выбрался автоматически, откройте **Система → Системные настройки**, найдите `which_element_editor` и выберите **cmx**.

Чтобы временно вернуть стандартное поле или другой редактор, измените значение той же настройки. Удалять CMX для этого не требуется.

> При удалении пакета выбор редактора сбрасывается. Таблица истории версий сохраняется.

## Где работает CMX

| Форма | Язык и особенности |
| --- | --- |
| Сниппеты | PHP без открывающего `<?php`; автодополнение MODX/xPDO API и PHP-функций |
| Плагины | PHP без открывающего `<?php`; браузерная и серверная проверка синтаксиса |
| Чанки | HTML, Fenom или Twig; для статических чанков язык определяется по расширению файла |
| Шаблоны | HTML с MODX-тегами, Fenom или Twig |
| Файлы | Язык определяется по расширению; PHP-файлы поддерживают полный `<?php`-документ |
| TV с типом ввода `cmx` | Язык и высота настраиваются в параметрах конкретного TV |
| CMX Scratchpad | Личный блокнот на дашборде менеджера |

Если для ресурса включён визуальный RTE, например TinyMCE, CMX не заменяет его.

## Возможности редактора

### Подсветка синтаксиса

CMX поддерживает:

- PHP, включая смешанные документы `PHP + HTML`;
- HTML с вложенными CSS и JavaScript;
- CSS, SCSS и Less;
- JavaScript и JSON;
- SQL;
- XML и SVG;
- Markdown;
- Fenom и Twig;
- MODX-теги `[[...]]`.

Каждая тема содержит собственные цвета для синтаксиса, MODX/Fenom-конструкций, скобок, диагностики и панелей редактора.

### Семантическая подсветка MODX-тегов

Отдельно выделяются:

- скобки `[[` и `]]`;
- флаг некэшированного вызова `!`;
- префиксы `$`, `*`, `+`, `%`, `~`, `++`;
- имена элементов, ресурсов, TV и настроек;
- разделитель `?`, свойства `&...`, фильтры `:...` и наборы `@...`;
- строки в обратных апострофах;
- комментарии `[[-...]]`;
- вложенные теги, включая конструкции вроде `[[~[[*id]]]]`.

### Автодополнение

Подсказки появляются автоматически или по `Ctrl+Space`.

| Контекст | Подсказки |
| --- | --- |
| `[[` и `[[!` | Сниппеты и префиксы типов MODX-тегов |
| `[[$` | Чанки |
| `[[*` | TV и поля ресурса; на форме ресурса - TV текущего шаблона |
| `[[+` | Поля ресурса и плейсхолдеры, уже встречающиеся в документе |
| `[[~` | Ресурсы с ID и заголовком |
| `[[++` | Системные настройки и их текущие значения |
| `[[%...` | Записи лексиконов на языке менеджера |
| `&свойство` | Параметры вызываемого сниппета или чанка, их описания и значения по умолчанию |
| `:фильтр` | Фильтры вывода MODX с описаниями и готовыми значениями |
| `@набор` | Наборы свойств |
| `{...` | Теги, блоки и модификаторы Fenom; теги и фильтры Twig |
| `{'имя` | Сниппеты и чанки внутри строк Fenom |
| `{'!pdoCrumbs' \| snippet : [...]}` | Параметры сниппета в многострочном Fenom-вызове |
| `{$...` | Переменные Fenom, поля ресурса и TV |
| `{$_modx->...` | Методы modX, объекты resource/user/config/placeholders |
| `$modx->...`, `$xpdo->...` | Методы MODX/xPDO API с сигнатурами |
| Обычное слово в PHP | Часто используемые PHP-функции и пользовательские сниппеты из `cmx.snippets` |

Дополнительно:

- уже использованные параметры скрываются из повторных подсказок;
- значения по умолчанию подставляются автоматически;
- после выбора префикса, параметра или фильтра может открываться следующий уровень подсказок;
- MODX-теги и Fenom-блоки могут закрываться автоматически;
- блочные Fenom-теги вставляются готовыми каркасами;
- пользовательские сниппеты задаются в формате `метка :: вставляемый текст`;
- описания подсказок локализуются на русском и английском языках.

### Переход к элементу

При включённой настройке `cmx.goto_definition` удерживайте `Ctrl` на Windows/Linux или `Cmd` на Mac и нажмите на имя в MODX-теге:

- `[[PdoPage]]` - открыть сниппет;
- `[[$header]]` - открыть чанк;
- `[[*tv_name]]` - открыть TV;
- `[[~42]]` - открыть ресурс с ID 42.

Элемент открывается **в новой вкладке браузера**, поэтому текущая форма редактирования не теряется.

### Подсказки при наведении

При включённой настройке `cmx.hovers` редактор показывает:

- заголовок и URI ресурса;
- описание сниппета, чанка или TV;
- описание поля ресурса;
- справку по фильтрам вывода MODX;
- справку по модификаторам Fenom.

### Поиск, замена и мультикурсоры

Панель поиска открывается по `Ctrl+F` или `Cmd+F` и поддерживает:

- обычный поиск и поиск по регулярному выражению;
- учёт регистра;
- поиск целых слов;
- переход к следующему и предыдущему совпадению;
- замену одного или всех совпадений;
- переход к номеру строки;
- русскую и английскую локализацию панели.

Для работы с несколькими вхождениями доступны `Ctrl/Cmd+D`, `Ctrl/Cmd+Shift+L`, добавление курсоров выше и ниже, а также прямоугольное выделение мышью с `Alt`/`Option`.

### Редактирование и форматирование

CMX включает:

- автозакрытие скобок, кавычек и HTML-тегов;
- подсветку парной скобки;
- необязательную раскраску скобок по уровням вложенности;
- строчные и блочные комментарии;
- увеличение и уменьшение отступа через `Tab` и `Shift+Tab`;
- мягкие табы с настраиваемой шириной;
- автоматический отступ при вводе;
- перемещение, копирование и удаление строк;
- сворачивание блоков кода;
- выделение всей строки кликом по её номеру;
- выделение диапазона строк протягиванием по номерам;
- подсветку активной строки и совпадений выделенного слова;
- отображение линий отступов и вертикальной линейки;
- подсветку и удаление конечных пробелов.

Форматирование отступов учитывает HTML, MODX-теги и структуру Fenom: тела `{if}`, `{foreach}`, `{switch}`, `{block}`, многострочные параметры сниппетов и закрывающие конструкции. Обрабатывается весь документ или только выделенные строки.

Команда вызывается кнопкой **«Выровнять код»**, из палитры команд или сочетанием:

- Windows/Linux: `Shift+Alt+F`;
- macOS: `Cmd+Shift+F`.

### Emmet

В поддерживаемых HTML, CSS и XML-контекстах аббревиатуры Emmet подчёркиваются при вводе и разворачиваются по `Tab`.

Например:

```text
ul.nav>li*5>a
```

Функция отключается настройкой `cmx.emmet`.

### Проверка PHP

При включённой настройке `cmx.php_lint` работают два независимых уровня:

1. **Проверка в браузере** - непарные и лишние скобки, незакрытые строки, комментарии и heredoc/nowdoc. Учитываются атрибуты PHP 8, интерполяция строк, смешанные PHP/HTML-документы и код сниппетов без `<?php`.
2. **Проверка через PHP CLI** - запуск `php -l` на сервере после паузы в редактировании. Путь к интерпретатору задаётся настройкой `cmx.php_path`.

Если PHP CLI недоступен или `exec()` запрещён хостингом, серверная проверка отключается, а браузерная продолжает работать.

### Проверка CSS

Настройка `cmx.css_lint` включает проверку CSS-файлов и блоков `<style>`:

- неизвестные свойства;
- вероятные опечатки с предложением похожего названия;
- незакрытые и лишние фигурные скобки;
- предупреждения для неизвестных свойств с вендорным префиксом.

CSS-переменные, распространённые хаки, SCSS/Less-конструкции, MODX/Fenom/Twig-теги не считаются ошибками.

### Проверка Fenom и MODX-тегов

Настройка `cmx.template_lint` включает диагностику:

- незакрытых и несоответствующих блочных тегов Fenom;
- незакрытых кавычек внутри тега;
- незакрытого MODX-тега `[[`;
- непарного обратного апострофа внутри MODX-тега;
- непарных скобок внутри Fenom-конструкций.

Сканер различает теги шаблонов и обычные фигурные скобки CSS/JavaScript, учитывает строки, комментарии и блоки `{ignore}`.

Ошибки подчёркиваются, а их количество отображается в строке состояния. При сохранении CMX может показать список критических ошибок и запросить подтверждение (`cmx.warn_on_save`). Сохранение не блокируется окончательно: пользователь может сознательно сохранить незавершённый код.

### Черновики

При включённой настройке `cmx.autosave` рабочая копия сохраняется в `localStorage` браузера текущего менеджера.

После сбоя или повторного открытия страницы CMX предлагает:

- сравнить сохранённый документ и черновик в side-by-side diff;
- восстановить черновик;
- удалить черновик.

Срок хранения задаётся настройкой `cmx.autosave_lifetime`. Черновики не отправляются на сервер.

### История версий

При включённой настройке `cmx.versions` CMX сохраняет снимки сниппетов, чанков, шаблонов, плагинов и ресурсов в таблицу `cmx_revision`.

Панель истории позволяет:

- просматривать время, автора и размер снимка;
- открывать версию в редакторе только для чтения;
- загрузить версию в текущий редактор без немедленного сохранения;
- копировать код версии;
- отметить две версии и сравнить их построчно;
- скачать историю элемента в JSON.

Количество хранимых снимков ограничивается настройкой `cmx.versions_max`. Повторные одинаковые снимки в течение короткого интервала не создаются. При удалении элемента его история также удаляется; при окончательной очистке корзины удаляется история соответствующих ресурсов. Файлы файлового менеджера не версионируются.

### Палитры команд и элементов

**Палитра команд** открывается по `Ctrl/Cmd+Shift+P` и содержит команды поиска, перехода к строке, форматирования, удаления конечных пробелов, комментирования, сворачивания блоков, смены темы и шрифта, переноса строк, истории, медиа-браузера и полноэкранного режима.

**Палитра элементов** открывается кнопкой `{ }`: позволяет найти сниппет, чанк, TV или ресурс и вставить соответствующий MODX-тег в позицию курсора.

### Медиа-браузер

Для HTML-документов с MODX-тегами кнопка изображения открывает штатный медиа-браузер MODX. Выбранный файл вставляется в редактор путём, а изображение - готовым тегом `<img>`.

Настройка: `cmx.media_button`.

### Темы и внешний вид

Доступны 12 вариантов оформления:

- Auto - следует системной светлой или тёмной теме;
- Manager - определяет цветовой режим менеджера;
- GitHub Light;
- Quiet Light;
- Solarized Light;
- One Dark;
- Dracula;
- Nord;
- Gruvbox Dark;
- VS Code Dark+;
- Monokai;
- Solarized Dark.

Тему можно менять кнопкой на панели, кликом по названию темы в строке состояния или через быстрое меню. Шрифт, размер шрифта и перенос строк настраиваются отдельно.

### Панель инструментов и строка состояния

На панели инструментов доступны: тема, быстрые настройки, полноэкранный режим, форматирование, палитра команд, вставка элемента, медиа-браузер и история версий. Состав зависит от настроек и типа документа.

Строка состояния показывает:

- номер строки и столбца;
- размер выделения;
- количество строк и символов;
- язык документа;
- текущую тему;
- количество ошибок и предупреждений.

Быстрое меню сохраняет тему, размер шрифта и перенос строк в браузере конкретного менеджера. Команда сброса возвращает системные значения.

### Раскладки клавиатуры

Настройка `cmx.keymap` поддерживает:

- `standard` - стандартные команды CodeMirror;
- `sublime` - дополнительные привычные сочетания Sublime Text;
- `vim` - режимы Normal/Insert/Visual, движения, операторы, поиск, регистры и макросы через `@replit/codemirror-vim`.

## TV с типом ввода CMX

CMX регистрирует собственный тип ввода для Template Variables.

1. Создайте или откройте TV.
2. На вкладке параметров ввода выберите тип **cmx**.
3. Задайте необязательные свойства:
   - `language` - `text/html`, `text/css`, `application/javascript`, `application/json`, `text/x-sql`, `application/xml`, `text/x-markdown` или `application/x-php`;
   - `height` - высота редактора в пикселях, минимум 100, по умолчанию 260.
4. Добавьте TV к нужному шаблону.

На странице ресурса TV отображается как полноценный CMX-редактор. Значение сохраняется как обычное TV и остаётся в редакторе после сохранения ресурса.

Функция отключается настройкой `cmx.tv`.

## Виджет CMX Scratchpad

**CMX Scratchpad** - личный блокнот с подсветкой кода для дашборда MODX.

Добавление: **Дашборд → Редактировать → Виджеты → CMX Scratchpad**.

Текст хранится только в `localStorage` браузера текущего менеджера и не отправляется на сервер.

## Хранение данных и права

- Черновики и Scratchpad хранятся локально в браузере пользователя.
- История версий хранится в базе данных текущего сайта MODX.
- Запросы автодополнения, лексиконов и истории выполняются через коннектор CMX с проверкой прав менеджера.
- Чтение и выгрузка истории ограничиваются правами на соответствующий тип элементов.
- Серверная PHP-проверка выполняется на текущем сервере; внешний сервис проверки не используется.
- Для `lint` и `getlexicons` дополнительно действует ограничение частоты запросов в сессии менеджера.
- Внешние CDN для загрузки редактора не требуются.
