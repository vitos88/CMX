# CMX — быстрые команды и горячие клавиши

Шпаргалка по командам, которые подключены в CMX 3.7 (CodeMirror 6). Сочетания сверены с `frontend/src/editor.js`, `frontend/src/keymaps.js` и используемыми keymap CodeMirror.

## Обозначения

- **Mod** — `Ctrl` в Windows/Linux и `Cmd` (`⌘`) в macOS.
- **Alt** — это `Option` (`⌥`) на Mac. Для буквенных команд, где macOS подставляет символы вместо букв, CMX использует отдельные сочетания без `Option`.
- `Shift`, `Alt`/`Option`, `Ctrl` и `Cmd` удерживаются вместе с указанной клавишей.
- Команды редактирования не работают в режиме только для чтения.
- Некоторые команды зависят от настроек `cmx.*`: автодополнение, поиск, Emmet и переход к элементу можно отключить.

## Основные команды

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Сохранить элемент или ресурс в MODX | `Ctrl+S` | `Cmd+S` |
| Отменить изменение | `Ctrl+Z` | `Cmd+Z` |
| Повторить изменение | `Ctrl+Y` или `Ctrl+Shift+Z` | `Cmd+Shift+Z` |
| Выделить всё | `Ctrl+A` | `Cmd+A` |
| Найти и заменить | `Ctrl+F` | `Cmd+F` |
| Перейти к строке | `Ctrl+Alt+G` | `Ctrl+G` |
| Открыть палитру команд CMX | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Выровнять отступы документа или выделенных строк | `Shift+Alt+F` | `Cmd+Shift+F` |
| Включить или выключить комментарий | `Ctrl+/` | `Cmd+/` |
| Включить или выключить блочный комментарий | `Shift+Alt+A` | `Shift+Ctrl+A` |
| Увеличить отступ | `Tab` или `Ctrl+]` | `Tab` или `Cmd+]` |
| Уменьшить отступ | `Shift+Tab` или `Ctrl+[` | `Shift+Tab` или `Cmd+[` |
| Автоматически выровнять отступы выделения | `Ctrl+Alt+\` | `Cmd+Alt+\` |

`Tab` и `Shift+Tab` меняют отступ текущей строки или всех выделенных строк. Если включён Emmet и перед курсором есть аббревиатура, `Tab` сначала разворачивает её.

## Строки и редактирование

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Новая строка с автоматическим отступом | `Enter` или `Shift+Enter` | `Enter` или `Shift+Enter` |
| Вставить пустую строку | `Ctrl+Enter` | `Cmd+Enter` |
| Переместить строку или выделенные строки вверх | `Alt+↑` | `Alt+↑` |
| Переместить строку или выделенные строки вниз | `Alt+↓` | `Alt+↓` |
| Скопировать строку или выделение вверх | `Shift+Alt+↑` | `Shift+Alt+↑` |
| Скопировать строку или выделение вниз | `Shift+Alt+↓` | `Shift+Alt+↓` |
| Удалить строку | `Ctrl+Shift+K` | `Cmd+Shift+K` |
| Удалить предыдущий символ | `Backspace` | `Backspace` |
| Удалить следующий символ | `Delete` | `Delete` |
| Удалить предыдущее слово | `Ctrl+Backspace` | `Alt+Backspace` |
| Удалить следующее слово | `Ctrl+Delete` | `Alt+Delete` |
| Удалить от курсора до начала строки | — | `Cmd+Backspace` |
| Удалить от курсора до конца строки | — | `Cmd+Delete` |
| Перейти к парной скобке | `Ctrl+Shift+\` | `Cmd+Shift+\` |
| Разрешить `Tab` переводить фокус из редактора | `Ctrl+M` | `Shift+Ctrl+M` |

Последняя команда переключает специальный режим доступности. Повторное нажатие возвращает обычное поведение `Tab`.

## Навигация и выделение

Добавление `Shift` к командам перемещения расширяет выделение.

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Перемещение на символ | `←` / `→` | `←` / `→` |
| Перемещение на строку | `↑` / `↓` | `↑` / `↓` |
| Перемещение на слово | `Ctrl+←` / `Ctrl+→` | `Alt+←` / `Alt+→` |
| Перемещение по синтаксическим узлам | `Alt+←` / `Alt+→` | `Ctrl+←` / `Ctrl+→` |
| В начало или конец строки | `Home` / `End` | `Home` / `End` или `Cmd+←` / `Cmd+→` |
| В начало или конец документа | `Ctrl+Home` / `Ctrl+End` | `Cmd+↑` / `Cmd+↓` |
| На страницу вверх или вниз | `PageUp` / `PageDown` | `PageUp` / `PageDown` или `Ctrl+↑` / `Ctrl+↓` |
| Выделить текущую строку | `Alt+L` | `Ctrl+L` |
| Выделить родительский синтаксический узел | `Ctrl+I` | `Cmd+I` |
| Свернуть мультивыделение до одного курсора | `Esc` | `Esc` |

Дополнительный способ в CMX: щёлкните по номеру строки, чтобы выделить её целиком вместе с переводом строки. Протягивание по номерам выделяет весь диапазон строк, включая последнюю.

## Поиск и замена

Эти сочетания доступны при включённой настройке `cmx.search_panel`.

| Действие | Сочетание |
| --- | --- |
| Открыть панель поиска | `Mod+F` |
| Следующее совпадение | `F3` или `Mod+G` |
| Предыдущее совпадение | `Shift+F3` или `Shift+Mod+G` |
| Перейти к строке | `Ctrl+Alt+G` в Windows/Linux, `Ctrl+G` в macOS |
| Выделить следующее вхождение | `Mod+D` |
| Выделить все вхождения | `Mod+Shift+L` |
| Закрыть панель поиска | `Esc`, когда фокус находится в панели |

В панели доступны поиск с учётом регистра, регулярные выражения, поиск целых слов, замена одного совпадения и замена всех совпадений.

## Автодополнение и Emmet

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Открыть автодополнение вручную | `Ctrl+Space` | `Ctrl+Space` |
| Следующий или предыдущий вариант | `↓` / `↑` | `↓` / `↑` |
| На страницу вариантов вниз или вверх | `PageDown` / `PageUp` | `PageDown` / `PageUp` |
| Применить выбранный вариант | `Enter` | `Enter` |
| Закрыть список подсказок | `Esc` | `Esc` |
| Развернуть аббревиатуру Emmet | `Tab` | `Tab` |

`Enter` применяет вариант только при открытом списке автодополнения. Emmet работает в поддерживаемых HTML/CSS/XML-контекстах при включённой настройке `cmx.emmet`.

## Команды CMX и MODX

| Действие | Команда |
| --- | --- |
| Палитра команд | `Mod+Shift+P` |
| Форматирование отступов | `Shift+Alt+F` в Windows/Linux, `Cmd+Shift+F` в macOS |
| Переход к элементу из MODX-тега | `Ctrl`-клик в Windows/Linux, `Cmd`-клик в macOS |
| Открытие элемента | В новой вкладке браузера при включённом `cmx.goto_definition` |
| Выделение строки | Клик по её номеру |
| Выделение диапазона строк | Протягивание по номерам строк |
| Вставка элемента MODX | Кнопка `{ }` на панели редактора |
| История версий | Кнопка с часами на панели редактора |
| Полноэкранный режим | Кнопка полноэкранного режима на панели редактора |
| Быстрые настройки темы, шрифта и переноса строк | Кнопка с шестерёнкой |

Переход работает для сниппетов, чанков, TV и ресурсов, например `[[Wayfinder]]`, `[[$header]]`, `[[*tv_name]]` и `[[~42]]`.

## Режим Sublime

Включается настройкой `cmx.keymap = sublime`. Все стандартные команды сохраняются; дополнительно действует более привычное сочетание:

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Выделить текущую строку | `Ctrl+L` | `Cmd+L` |

Перемещение и копирование строк, удаление строки и переключение комментария используют те же сочетания, что в таблицах выше.

## Режим Vim

Включается настройкой `cmx.keymap = vim`. Поддерживаются режимы Normal, Insert, Visual и Visual Line, операторы, движения, регистры и макросы.

| Действие | Команда |
| --- | --- |
| Войти в Insert | `i`, `a`, `o` или `O` |
| Вернуться в Normal | `Esc` |
| Перемещение | `h`, `j`, `k`, `l`, `w`, `b`, `e`, `0`, `^`, `$`, `gg`, `G` |
| Visual / Visual Line | `v` / `V` |
| Удалить символ / строку | `x` / `dd` |
| Скопировать строку | `yy` |
| Вставить после / перед курсором | `p` / `P` |
| Отменить / повторить | `u` / `Ctrl+R` |
| Поиск | `/`, затем `n` и `N` для навигации |
| Записать макрос | `q` + имя регистра; повторное `q` завершает запись |
| Выполнить макрос | `@` + имя регистра |
| Сохранение формы MODX | `Mod+S` — использует штатное сохранение менеджера |
